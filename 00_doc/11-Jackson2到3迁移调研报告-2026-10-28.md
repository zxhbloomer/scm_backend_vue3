## 0. TL;DR（先看这 6 条）

| # | 结论 | 证据等级 |
|---|---|---|
| 1 | Jackson 3 的包名从 `com.fasterxml.jackson.*` 迁到 `tools.jackson.*`，**唯一例外是 `jackson-annotations` 仍留在 `com.fasterxml.jackson.annotation`** | 官方（OpenRewrite 配方 unchanged 用例）+ 本机实测（jackson-annotations 2.21 仍在依赖树） |
| 2 | Spring Boot 4 **只自动配置 Jackson 3**（`tools.jackson.databind.json.JsonMapper`）；Jackson 2 的自动配置已废弃，需显式引入 `spring-boot-jackson2` 模块才恢复 | 官方（spring.io 博客 + Boot 4 迁移指南） |
| 3 | Jackson 3 的 `ObjectMapper` **是不可变构建产物**：`new ObjectMapper().configure(...)` 那套 setter 用法不再成立，必须走 `JsonMapper.builder().…build()` | 官方（3.0 发布说明 / 迁移指南） |
| 4 | Jackson 3 **内建 java.time 与 Optional/Stream 支持**（`tools.jackson.databind.ext.javatime.*`、`ext.jdk8.*` 已在 databind jar 内），`JavaTimeModule` / `Jdk8Module` 不再需要注册 | **本机实测**（jackson-databind-3.0.2.jar 包结构） |
| 5 | 日期默认值变了：Jackson 3 默认 `WRITE_DATES_AS_TIMESTAMPS = false`（输出 ISO-8601），且该开关**从 `SerializationFeature` 移到 `DateTimeFeature`** | 官方（3.0 迁移说明）+ **本机实测**（`tools.jackson.databind.cfg.DateTimeFeature`） |

## 1. 接口规范（Jackson 2 → 3 映射表）

### 1.1 依赖坐标

| Jackson 2 | Jackson 3 | 说明 |
|---|---|---|
| `com.fasterxml.jackson.core:jackson-core` | `tools.jackson.core:jackson-core` | 包名 `tools.jackson.core` |
| `com.fasterxml.jackson.core:jackson-databind` | `tools.jackson.core:jackson-databind` | **groupId 是 `tools.jackson.core`，不是 `tools.jackson.databind`** |
| `com.fasterxml.jackson.core:jackson-annotations` | **不变** | 仍是 `com.fasterxml.jackson.core:jackson-annotations` |
| `com.fasterxml.jackson.datatype:jackson-datatype-jsr310` | 删除 | 已内建到 databind |
| `com.fasterxml.jackson.datatype:jackson-datatype-jdk8` | 删除 | 已内建到 databind |
| `com.fasterxml.jackson.module:jackson-module-parameter-names` | 仍存在（可选） | 需按需引入 |
| Spring Boot 属性 `jackson-bom.version` | Boot 4 中该属性控制 **Jackson 3** BOM；Jackson 2 BOM 由 **`jackson-2-bom.version`** 控制 | OpenRewrite 配方 `MigrateJacksonBomProperty` 专门处理这条 |

### 1.2 类名 / API 迁移（本报告只列有官方用例或本机实测支撑的）

| 用途 | Jackson 2 | Jackson 3 | 证据 |
|---|---|---|---|
| JSON 树节点 | `com.fasterxml.jackson.databind.JsonNode` / `node.ObjectNode` / `node.ArrayNode` | `tools.jackson.databind.JsonNode` / `node.ObjectNode` / `node.ArrayNode` | 官方配方 |
| 泛型类型引用 | `com.fasterxml.jackson.core.type.TypeReference` | `tools.jackson.core.type.TypeReference` | 官方配方 |
| 解析器 | `com.fasterxml.jackson.core.JsonParser` | `tools.jackson.core.JsonParser` | 官方配方 |
| 生成器 | `com.fasterxml.jackson.core.JsonGenerator` | `tools.jackson.core.JsonGenerator` | 官方配方 |
| JSON 异常 | `com.fasterxml.jackson.core.JsonProcessingException`（**checked**） | `tools.jackson.core.JacksonException`（**unchecked**，无需 `throws`/`try-catch` 编译强制） | 官方配方（StdDeserializer 用例删掉 `throws IOException`） |
| 写流异常 | `JsonGenerationException(message, gen)` | `tools.jackson.core.exc.StreamWriteException(gen, message)`（注意**参数顺序反了**） | 官方配方 Example 17 |
| Token 枚举 | `JsonToken.FIELD_NAME` | `JsonToken.PROPERTY_NAME` | 官方配方 Example 16 |
| TypeFactory 单例 | `TypeFactory.defaultInstance()` | `TypeFactory.createDefaultInstance()` | 官方配方 Example 19 |
| JsonFactory 构建 | `new JsonFactoryBuilder().build()` | `JsonFactory.builder().build()`，且**类搬到 `tools.jackson.core.json.JsonFactory`** | 官方配方 Example 20 |
| 自定义序列化器基类 | `JsonObjectSerializer` | `ObjectValueSerializer` | 社区（Boot 4 M3 迁移小结） |
| 特性开关（序列化） | `SerializationFeature.WRITE_DATES_AS_TIMESTAMPS` | **`DateTimeFeature.WRITE_DATES_AS_TIMESTAMPS`**（其余 `SerializationFeature` 仍在 `tools.jackson.databind.SerializationFeature`） | **本机实测** |
| 注解 | `@JsonProperty` `@JsonFormat` `@JsonInclude` `@JsonIgnore` `@JsonTypeInfo` `@JsonSubTypes` `@JsonAutoDetect` `@JsonIgnoreProperties` | **全部不变**（仍在 `com.fasterxml.jackson.annotation`） | 官方配方 + 本机实测 |

> 重要边界：**注解不用改**，改的只有「数据绑定运行时 API」。这意味着一个项目里常见形态是「25 个文件只写注解（0 改动）+ 少量文件持有 ObjectMapper（要改）」。

### 1.3 Spring 生态侧的配套改名（同一次升级必须一起做）

| 组件 | Jackson 2 用法 | Boot 4 / Spring 7 用法 | 证据 |
|---|---|---|---|
| Spring MVC / RestTemplate 转换器 | `MappingJackson2HttpMessageConverter` | `JacksonJsonHttpMessageConverter`（新类；`MappingJackson2HttpMessageConverter` 在 spring-web 7.0.10 里**仍然存在**，属兼容保留） | **本机实测**（spring-web-7.0.10.jar 类清单） |
| Spring AMQP 消息转换器 | `Jackson2JsonMessageConverter`（4.0 起 `@Deprecated(forRemoval=true)`） | `JacksonJsonMessageConverter`（Jackson 3） | 官方（Spring AMQP 4.0 javadoc） |
| Spring Data Redis 序列化器 | `Jackson2JsonRedisSerializer` / `GenericJackson2JsonRedisSerializer` / `Jackson2HashMapper` | `JacksonJsonRedisSerializer` / `GenericJacksonJsonRedisSerializer` / `JacksonHashMapper`；`RedisSerializer.json()` 从 4.0 起默认 Jackson 3 | 官方（Spring Data Redis 4.x 迁移指南） |
| 自定义器 | `Jackson2ObjectMapperBuilderCustomizer` | `JsonMapperBuilderCustomizer` | 官方（Boot 4 迁移指南） |
| 组件注解 | `@JsonComponent` / `@JsonMixin` | `@JacksonComponent` / `@JacksonMixin` | 官方（Boot 4 迁移指南） |
| 配置属性前缀 | `spring.jackson.*` | Jackson 3 用 `spring.jackson.*`；Jackson 2 用 `spring.jackson2.*` | 官方（Boot 4 迁移指南） |

## 2. 基础使用

### 2.1 Boot 4 已经替你做了什么

Boot 4 的 `JacksonAutoConfiguration` 注册了三个关键 bean（本机 javap 实测 Boot 4.1.2）：

| bean | 类型 | 备注 |
|---|---|---|
| `jsonFactory` | `tools.jackson.core.JsonFactory` | |
| `jsonMapperBuilder` | `tools.jackson.databind.json.JsonMapper.Builder` | 供自定义器修改 |
| `jacksonJsonMapper` | `tools.jackson.databind.json.JsonMapper`（**继承 `tools.jackson.databind.ObjectMapper`**） | 应用里注入 `ObjectMapper` 能拿到它 |

所以：**业务代码要 ObjectMapper，正确做法是 `@Autowired ObjectMapper` / 构造注入，而不是 `new ObjectMapper()`。**

### 2.2 不要 `new`，要用 builder（不可变）

```java
// Jackson 2 写法（编译期已不成立：Jackson 3 的 configure/setVisibility 返回新实例或已移除）
ObjectMapper om = new ObjectMapper();
om.configure(SerializationFeature.FAIL_ON_EMPTY_BEANS, false);
om.registerModule(new JavaTimeModule());

// Jackson 3 正确写法
ObjectMapper om = JsonMapper.builder()
        .disable(SerializationFeature.FAIL_ON_EMPTY_BEANS)   // java.time 已内建，无需 JavaTimeModule
        .build();
```

### 2.3 最小可用示例

```java
import tools.jackson.databind.json.JsonMapper;
import tools.jackson.databind.ObjectMapper;

ObjectMapper mapper = JsonMapper.builder().build();
String json = mapper.writeValueAsString(obj);
MyDto dto = mapper.readValue(json, MyDto.class);
JsonNode node = mapper.readTree(json);          // tools.jackson.databind.JsonNode
```

## 3. 进阶技巧（优化点）

1. **单例复用，别在方法里 `new`**。Jackson 的 `ObjectMapper` 构造成本高（反射内省缓存），Jackson 3 的不可变设计天然鼓励「配好一次、全局复用」。项目里每个 `new ObjectMapper()` 都是一次冷启动开销 + 一份缓存。
2. **用 Boot 暴露的 builder 定制，而不是自建 mapper**：注册 `JsonMapperBuilderCustomizer`（Jackson 3）即可全局生效，同时把配置集中到一处，避免 3 个地方 3 套不一致的 mapper。
3. **属性驱动优先**：能用 `spring.jackson.*` 表达的不要写 Java 配置。Jackson 3 下日期时间行为由 `spring.jackson.datatype.datetime.*` 控制（`DateTimeFeature` 映射），而不是 `spring.jackson.serialization.write-dates-as-timestamps`（该属性在 Jackson 3 下已不适用）。
4. **模块自动发现**：Jackson 3 通过 `ServiceLoader` 发现模块，自有 `Module` 打包后在 classpath 上即被注册；如不希望被自动注册，用 `MapperBuilder.disable(JsonMapper.Feature...)`/关闭 `MapperFeature` 自动发现（详见官方的 builder 配置项）。
5. **自定义 serializer 基类迁移**：`JsonObjectSerializer` → `ObjectValueSerializer`；`StdDeserializer` 子类构造里 `this(null)` 改为 `this(String.class)`（官方配方 Example 18）。

## 4. 巧妙用法 / 社区实践

1. **OpenRewrite 一把梭**：`org.openrewrite.java.jackson.UpgradeJackson_2_3` 处理坐标、import、`JsonFactory`、`JsonToken`、异常重命名等机械改动；`org.openrewrite.java.spring.boot4.UpgradeSpringBoot_4_0` 处理 Boot 4 的整体迁移（含 `spring-boot-starter-aop` → `spring-boot-starter-aspectj` 这类依赖改名）。
   - 命令行（官方文档给出，注意新版配方仓库需认证）：
     ```
     mvn -U org.openrewrite.maven:rewrite-maven-plugin:run \
       -Drewrite.recipeArtifactCoordinates=org.openrewrite.recipe:rewrite-jackson:RELEASE \
       -Drewrite.activeRecipes=org.openrewrite.java.jackson.UpgradeJackson_2_3 \
       -Drewrite.exportDatatables=true
     ```
   - **注意**：OpenRewrite 官方文档当前声明配方制品已迁到需认证的 Code Genome Project 仓库；离线/内网环境未必能直接用，需评估。
2. **双栈过渡**（官方承认的过渡路径）：Boot 4 仍对 Jackson 2 提供依赖管理，只要加 `spring-boot-jackson2` 依赖 + `spring.http.converters.preferred-json-mapper=jackson2`，MVC 仍可继续用 Jackson 2 的映射器；Spring AMQP/Spring Data Redis 也保留了 Jackson 2 的旧类（标 `forRemoval`）。
   - 代价：**Jackson 2 自动配置已废弃，Boot 明确表示未来 4.x 会移除**，属于技术债，只适合"先把 Boot 4 跑起来"的过渡期。
3. **Spark/社区经验**：`RedisSerializer.json()` 从 Spring Data Redis 4.0 起默认 Jackson 3，**存量 Redis 数据要先用 `GenericJackson2JsonRedisSerializer` 读、迁移后再切**（官方迁移指南明确写了这一点）——这是"优雅迁移"的关键手法。

## 5. 注意事项（踩坑清单）

1. **日期格式默认值变化**：Jackson 3 默认输出 ISO-8601（`2026-10-28T15:42:28`），Jackson 2 默认输出时间戳（毫秒数）。凡前端依赖时间戳的地方都会变。要恢复旧行为用 `DateTimeFeature.WRITE_DATES_AS_TIMESTAMPS`，但这只是"回退旧行为"，不是推荐方向。
2. **异常语义变了**：Jackson 3 的 `JacksonException` 是 **unchecked**。原先 `catch (JsonProcessingException e)` 的代码块在 Jackson 3 下**编译不过**（类不存在）；改成 `catch (JacksonException e)` 后逻辑仍要自查：因为不再强制捕获，静默失败的路径可能变多。
3. **`ObjectMapper` 不可变**：所有 `configure()` / `setXxx()` 链式改配置在 Jackson 3 都要改成 builder。**不要**试图把 Boot 注入的 mapper 包一层再改。
4. **`JsonToken.FIELD_NAME` → `PROPERTY_NAME`**：手写 parser 的代码必须改，否则编译失败（枚举常量被删）。
5. **别把 Jackson 2 的 mapper 和 Jackson 3 的 mapper 混用**：两个栈的 `JsonNode`/`TypeReference` 是不同类型，序列化器互不兼容；混用会在运行期出现"能编译但反序列化出空对象"的行为。
6. **`jackson-annotations` 版本要够新**：Spring Data Redis 4 文档要求 Jackson 3 场景下 `com.fasterxml.jackson.core:jackson-annotations` 为较新版本（本机 Boot 4.1.2 管理为 2.21）。
7. **MQ/Redis 存量消息**：切换消息转换器/序列化器后，**旧消息与新消息格式可能不兼容**；滚动升级或多实例并存时必须有兼容策略（先双读、后单写）。
8. **自动配置缺失导致的报错长什么样**：Boot 4 下若代码里 `@Autowired ObjectMapper`（Jackson 2 的 `com.fasterxml.jackson.databind.ObjectMapper`）会直接启动失败——因为自动配置只提供 `tools.jackson.*` 的 mapper。报错形态是 `Parameter 0 of constructor in … required a bean of type 'com.fasterxml.jackson.databind.ObjectMapper' that could not be found`。

## 6. 真实代码片段（来自官方/社区的 before→after）

### 6.1 import + JsonFactory（OpenRewrite 官方用例 Example 20）

```java
// Before
import com.fasterxml.jackson.annotation.JsonProperty;
import com.fasterxml.jackson.core.JsonFactory;
import com.fasterxml.jackson.core.JsonFactoryBuilder;
import com.fasterxml.jackson.databind.ObjectMapper;

// After（注意 @JsonProperty 的 import 原封不动）
import com.fasterxml.jackson.annotation.JsonProperty;
import tools.jackson.databind.ObjectMapper;
import tools.jackson.core.json.JsonFactory;

JsonFactory factory = JsonFactory.builder().build();   // Before: new JsonFactoryBuilder().build()
```

### 6.2 StdDeserializer（Example 18）：`throws IOException` 消失、`this(null)` → `this(String.class)`

```java
// Before
public MyDeserializer() { this(null); }
@Override
public String deserialize(JsonParser p, DeserializationContext ctxt) throws IOException { … }

// After（JsonParser/DeserializationContext/StdDeserializer 全部 tools.jackson.*，且不再 throws）
public MyDeserializer() { this(String.class); }
@Override
public String deserialize(JsonParser p, DeserializationContext ctxt) { … }
```

### 6.3 Spring Data Redis 4 官方迁移示例（存量数据兼容）

```java
// 迁移期：继续用 Jackson 2 序列化器读老数据
RedisSerializer<Object> serializer = new GenericJackson2JsonRedisSerializer();
// 迁移后：切到 Jackson 3
RedisSerializer<Object> serializer = new GenericJacksonJsonRedisSerializer();
```
