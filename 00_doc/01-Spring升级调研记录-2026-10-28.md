## 五、Jackson 3 专题（重点：与 fastjson2 的真实关系）

### 5.1 项目实测数字

| | fastjson2 | Jackson |
|---|---|---|
| import 处数 | **413** | 63 |
| 涉及文件 | **264** | 42 |

Jackson 的 63 处中：
- **26 个文件只有注解**（`@JsonProperty`×13、`@JsonFormat`×11、`@JsonTypeInfo`、`@JsonSubTypes`）→ Jackson 3 **无需改动**（注解仍在 `com.fasterxml.jackson.core:jackson-annotations`）
- **16 个文件真正调用 API**（`ObjectMapper`×15、`JsonParser`×3、`SerializationFeature`×3、`JsonProcessingException`×3、`TypeReference`×2、`JavaTimeModule`×2、`JsonGenerator`、`Jdk8Module`）

### 5.2 业务 JSON 出口本来就不是 Jackson

- `scm-framework\...\config\messageconverter\CallbackMappingJackson2HttpMessageConverter.java:68` → `extends FastJsonHttpMessageConverter`
- `scm-framework\...\spring\ActionInterceptorConfig.java:67-69` → `configureMessageConverters` 注册该转换器

即 `@RestController` 的请求/响应体走 **fastjson2**，业务 DTO 序列化与 Jackson 无关。

### 5.3 Jackson 3 真正影响的是 5 条框架管线

| 位置 | 现状 | Boot 4 处理 |
|---|---|---|
| `scm-redis\...\RedisCacheAutoConfiguration.java:79-89,114-123` | `Jackson2JsonRedisSerializer` + `setObjectMapper` | SDR 4.0 已 `@Deprecated(forRemoval)` → `JacksonJsonRedisSerializer` / `GenericJacksonJsonRedisSerializer`；`RedisSerializer.json()` 默认改 Jackson 3 |
| `scm-mq\...\ConsumerConfiguration.java:37`、`scm-ai\...\RabbitMQConfig.java:81` | `Jackson2JsonMessageConverter` | AMQP 4.0 `@Deprecated(forRemoval, since 4.0)` → `JacksonJsonMessageConverter`（Jackson 3） |
| `scm-framework\...\RestTemplateConfiguration.java:56-57` | `getObjectMapper().configure(FAIL_ON_EMPTY_BEANS,false)` | Jackson 3 mapper 不可变 → `JsonMapper.builder()...build()` |
| `pom.xml:725` 等 3 处 | `jjwt-jackson` | 换 `jjwt-gson 0.13.0` |
| `scm-core-clickhouse\pom.xml:64` | 显式 jackson-databind | 删声明 |

### 5.4 Jackson 3 的破坏性变化（官方 MIGRATING_TO_JACKSON_3.md）

- `ObjectMapper`/`JsonFactory` **不可变**，必须 `JsonMapper.builder()`
- 异常全部 **unchecked**：`JsonProcessingException`→`JacksonException`（不再 extends IOException）、`JsonMappingException`→`DatabindException`
- **Java 8 模块内建并移除**：`JavaTimeModule`/`Jdk8Module` 不复存在，日期配置改 `DateTimeFeature`
- 注解不变（2.x artifact）；包名 `com.fasterxml.jackson.*` → `tools.jackson.*`；Java 17 底线
- 默认值变化：日期默认 **ISO-8601 字符串**（Jackson 2 默认时间戳数组）；**客户端向 primitive 字段传 `null` 由静默接受变为 400**

### 5.5 fastjson2 侧的硬点（以前被忽略）

Spring Framework 7 已弃用 `WebMvcConfigurer.configureMessageConverters(List)` 与 `extendMessageConverters(List)`（`@Deprecated(since="7.0", forRemoval=true)`），替代为 `configureMessageConverters(HttpMessageConverters.ServerBuilder)`；Framework 7 同时新增 `JacksonJsonHttpMessageConverter`（Jackson 3 版）。
fastjson2 官方 `docs/Spring/spring_support_en.md` 已给出 "Spring MVC 7.0 and Above" 的接法（`HttpMessageConverters.ServerBuilder#withJsonConverter`），但 artifact 仍是 `fastjson2-extension-spring6`，**无 spring7 命名模块** → 必须实测。

### 5.6 三条路线（决策项）

| 路线 | 做法 | 代码改动 | 代价 |
|---|---|---|---|
| A 过渡 | Boot 4.1.2 + `spring-boot-jackson2` 模块 + `spring.jackson2.*` 属性 | **0** | 官方明示该模块 deprecated、未来 4.x 移除，等于排一次二次迁移 |
| B 纯 Jackson 3 | Boot 4.1.2 + Jackson 3 | **16 文件 + 3 管线 + 2 pom** | 一次性结清；需回归日期格式、null→primitive、Redis 存量值、RabbitMQ 存量消息 |
| C 去 Jackson | 全仓改 fastjson2（Redis 用已有的 `FastJsonRedisSerializer`） | 413 处不动业务，但 16 处 Jackson 改 fastjson + 框架内部仍带 Jackson 3 | 依赖 fastjson2 在 Framework 7 的实测结果，且框架内部（springdoc/Flowable/ES）仍引入 Jackson 3 |

> 补充：Boot 4.0 迁移指南提供的兼容开关为 `spring.jackson.use-jackson2-defaults=true`、`spring.jackson2.*`；改名 `Jackson2ObjectMapperBuilderCustomizer`→`JsonMapperBuilderCustomizer`、`@JsonComponent`→`@JacksonComponent`。
