## 0. 修改控制规则（先定规矩，再动手）

**状态机（每条改动只能沿箭头前进，不允许跳级）**

```
未开始 → 已改 → 已编译 → 已验证 → 已合并
                 ↘ 回滚（记录原因）
```

**四条硬规则**

1. 一条 `C-*` 只允许改一个文件的连续区域；跨文件必须拆条。
2. 每改完一条，立刻回填 `commit` 短哈希与 `mvn -pl <模块> compile` 结果；没回填的视为未完成。
3. `已验证` 必须有可复现的命令（编译 / 启动 / SQL 查询），口头"跑通了"不计数。
4. 任何一条触发 `回滚`，当扇区停止推进，先把原因写进 `05` 再继续。
